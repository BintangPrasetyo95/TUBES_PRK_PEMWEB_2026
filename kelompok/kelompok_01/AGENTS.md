Agent Instructions
UI/UX and Frontend Design
Whenever a task involves UI/UX, frontend design, visual styling, layout, components, or responsive behavior:
1. Read and apply the design-taste-frontend skill before making design decisions.
2. If the task is to improve, modernize, or redesign an existing interface, also read and apply the redesign-existing-projects skill if it is installed and available.
3. Inspect the existing project structure, conventions, and implementation before changing files.
4. Preserve the project's existing technology stack, architecture, authentication, data flow, and working functionality unless the user explicitly requests otherwise.
5. Do not settle for superficial changes such as only changing colors, shadows, border radii, or fonts. Reconsider hierarchy, composition, spacing, typography, and interaction patterns.
6. Verify the result in a browser at desktop and mobile sizes when browser tooling is available. Fix visible issues before reporting completion.
7. If a requested skill is unavailable, say so clearly and continue using the available design guidance.
Do not claim a skill was used unless its SKILL.md was actually read during the task.
